# 📦 Stock Management System

## Project Overview
The Stock Management System is a web-based inventory management application developed using Python Flask and SQLite. It helps users manage products, monitor stock, and generate inventory reports through a simple and user-friendly interface.

## Features
- 🔐 User Login Authentication
- 📊 Dashboard
- ➕ Add Product
- 📦 View Products
- ✏️ Edit Product
- 🗑️ Delete Product
- 🔍 Search Products
- 🗂️ Categories Page
- 📑 Inventory Reports
- 🚪 Logout
- 💾 SQLite Database
- 📱 Responsive User Interface

## Technologies Used
- Python
- Flask
- SQLite
- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
   ```

2. Open the project folder.

3. Install Flask:
   ```bash
   pip install flask
   ```

4. Run the project:
   ```bash
   py app.py
   ```

5. Open your browser:
   ```
   http://127.0.0.1:5000
   ```
